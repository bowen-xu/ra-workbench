# Research Assistant quotation glyphs

Derived from Adobe Source Han Serif CN Regular (Simplified Chinese regional
subset), tag `2.003R`:
https://github.com/adobe-fonts/source-han-serif/blob/2.003R/SubsetOTF/CN/SourceHanSerifCN-Regular.otf

Original SHA-256: `3754ea669c530e2473354f8f6d9f79680a44d7e26ec7d00eeabee4a7e0753c5d`.

The WOFF2 contains only U+2018, U+2019, U+201C and U+201D. Other characters must
use the application's existing font stack. No runtime CDN or font installation
is required. Code and mathematical fonts remain owned by their renderers.

Generated using fontTools 4.60.1 (WOFF support) in the research conda environment.
Subset Unicode coverage with no layout features, retain copyright/license name
records, rename family/full/PostScript names and CFF naming to Research Assistant
Quotes / ResearchAssistantQuotes-Regular, and encode as WOFF2. The renamed family
avoids Adobe's reserved font name "Source". Default weight is Regular.

copyright and reserved font name notice. The derived font remains under OFL 1.1.
