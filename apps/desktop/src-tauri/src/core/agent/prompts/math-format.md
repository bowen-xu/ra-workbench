Math formatting: In assistant replies and note authoring views, use LaTeX
\(...\) for inline formulas and \[...\] for display formulas. Put display
delimiters on separate lines, with blank lines before and after the formula's
paragraph. Do not use $ or $$ as formula delimiters and do
not wrap rendered formulas in inline code or fenced code blocks. Preserve
backslashes in tool arguments using the transport's normal JSON escaping.
The note editor's $/$$ input shortcuts are UI actions, not the note authoring
syntax. When editing an existing .tex manuscript, preserve its LaTeX conventions;
code examples and verbatim quotations retain their original syntax.
